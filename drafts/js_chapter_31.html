Глава 32. Отладка и диагностика

Типы ошибок

🔴 Синтаксические ошибки

Грамматические ошибки в коде. Скрипт не запустится.

// Ошибка: пропущена закрывающая скобка if (x > 0 { console.log('positive'); }
🟡 Ошибки выполнения (Runtime)

Возникают во время работы программы.

// Ошибка: переменная не определена console.log(unknownVariable); // ReferenceError
🔵 Логические ошибки

Код работает, но результат не тот, что ожидался.

// Ошибка: неправильный оператор if (x = 5) { // должно быть x === 5 console.log('x равно 5'); }

Консоль разработчика

console.log() и другие методы

// Простой вывод console.log('Привет'); // Несколько значений console.log('x =', x, 'y =', y); // Объекты (развёрнутый вид) console.log({name: 'Alice', age: 25}); // console.table() - таблица console.table([{name: 'Alice'}, {name: 'Bob'}]); // console.error() - ошибка (красным) console.error('Произошла ошибка!'); // console.warn() - предупреждение (жёлтым) console.warn('Это предупреждение'); // console.time() / console.timeEnd() - замер времени console.time('myTimer'); // ... код ... console.timeEnd('myTimer'); // myTimer: 123ms

Отладчик (Debugger)

Точки останова (Breakpoints)

function calculate(a, b) { debugger; // программа остановится здесь const sum = a + b; return sum; }
💡 Как использовать отладчик
  1. Откройте DevTools (F12)
  2. Перейдите на вкладку Sources
  3. Кликните на номер строки, чтобы поставить breakpoint
  4. Используйте кнопки:
    • Step Over (F10) - выполнить строку
    • Step Into (F11) - войти в функцию
    • Step Out (Shift+F11) - выйти из функции
    • Continue (F8) - продолжить до следующего breakpoint

Распространённые ошибки

1. Незакрытые скобки

// ❌ Ошибка function test() { console.log('Hello'; } // пропущена ) // ✅ Правильно function test() { console.log('Hello'); }

2. Проблемы с кавычками

// ❌ Ошибка const name = "It's a string'; // смешаны ' и " // ✅ Правильно const name = "It's a string"; // или const name = 'It\'s a string'; // экранирование

3. Чувствительность к регистру

// ❌ Ошибка const myVariable = 10; console.log(myvariable); // ReferenceError // ✅ Правильно console.log(myVariable);

4. Область видимости

// ❌ Ошибка function test() { const x = 10; } console.log(x); // ReferenceError: x не определена // ✅ Правильно const x = 10; // глобальная переменная function test() { console.log(x); // доступна внутри функции }

5. Асинхронные операции

// ❌ Ошибка let data; fetch('https://api.example.com/data') .then(response => response.json()) .then(json => data = json); console.log(data); // undefined (ещё не загрузилось) // ✅ Правильно async function getData() { const response = await fetch('https://api.example.com/data'); const data = await response.json(); console.log(data); // теперь данные есть }

Глава 31. Best Practices и оптимизация

Оптимизация кода

1. Сохранение параметров в переменных

// ❌ Плохо: повторяющиеся значения document.querySelector('.box').style.color = '#FF0000'; document.querySelector('.box').style.fontSize = '16px'; document.querySelector('.box').style.padding = '10px'; // ✅ Хорошо: сохранили в переменную const box = document.querySelector('.box'); box.style.color = '#FF0000'; box.style.fontSize = '16px'; box.style.padding = '10px';

2. Сохранение параметров в объектах

// ✅ Группируем настройки const config = { colors: { primary: '#0066cc', secondary: '#6c757d', success: '#28a745' }, delays: { animation: 300, tooltip: 200 }, apiUrl: 'https://api.example.com' }; // Использование element.style.color = config.colors.primary; setTimeout(showTooltip, config.delays.tooltip);

3. Тернарный оператор

// ❌ Длинный if-else let status; if (isLoggedIn) { status = 'Авторизован'; } else { status = 'Гость'; } // ✅ Тернарный оператор const status = isLoggedIn ? 'Авторизован' : 'Гость';

4. Switch вместо множественных if-else

// ❌ Множественные if-else if (day === 'Monday') { console.log('Начало недели'); } else if (day === 'Friday') { console.log('Конец недели'); } else if (day === 'Saturday' || day === 'Sunday') { console.log('Выходные'); } // ✅ Switch switch(day) { case 'Monday': console.log('Начало недели'); break; case 'Friday': console.log('Конец недели'); break; case 'Saturday': case 'Sunday': console.log('Выходные'); break; }

5. Деструктуризация

// ❌ Старый способ const firstName = user.firstName; const lastName = user.lastName; const age = user.age; // ✅ Деструктуризация const {firstName, lastName, age} = user; // Для массивов const [first, second] = [1, 2, 3]; console.log(first); // 1

6. Spread оператор

// Копирование массива const arr1 = [1, 2, 3]; const arr2 = [...arr1]; // [1, 2, 3] // Объединение массивов const combined = [...arr1, ...arr2]; // Копирование объекта const user = {name: 'Alice', age: 25}; const userCopy = {...user}; // Добавление свойств const userWithEmail = {...user, email: 'alice@example.com'};

7. Template literals

// ❌ Конкатенация строк const greeting = 'Привет, ' + name + '! Тебе ' + age + ' лет.'; // ✅ Template literals const greeting = `Привет, ${name}! Тебе ${age} лет.`; // Многострочные строки const html = `

${title}

${text}

`;

8. Стрелочные функции

// ❌ Обычная функция const numbers = [1, 2, 3]; const doubled = numbers.map(function(n) { return n * 2; }); // ✅ Стрелочная функция const doubled = numbers.map(n => n * 2); // С несколькими параметрами const sum = (a, b) => a + b; // С телом функции const process = (data) => { const result = data * 2; return result + 10; };

Минификация и сжатие

💡 Минификация кода

Минификация удаляет пробелы, комментарии и сокращает имена переменных.

Инструменты:

  • JavaScript Minifier
  • Terser (NPM)
  • UglifyJS

Ускорение загрузки

1. Defer и Async

<!-- defer: загрузка параллельно, выполнение после HTML --> <script src="script.js" defer></script> <!-- async: загрузка и выполнение параллельно --> <script src="script.js" async></script>

2. Размещение скриптов

<!-- ❌ Плохо: в <head> блокирует рендеринг --> <head> <script src="large-script.js"></script> </head> <!-- ✅ Хорошо: перед </body> или с defer --> <body> <!-- контент --> <script src="script.js"></script> </body>
