Глава 11. DOM (Document Object Model)

Что такое DOM?

DOM — это программный интерфейс для HTML и XML документов.

💡 Структура DOM

Каждый HTML-элемент представлен объектом (узлом).

Поиск элементов

// getElementById const header = document.getElementById('header');

Изменение содержимого

// textContent div.textContent = 'Новый текст';

Создание своего элемента HTML

class HelloMetanit extends HTMLElement { constructor() { super(); this.innerText = "Привет!"; } } customElements.define("hello-metanit", HelloMetanit);
